# Lemmings4_PD
End-to-end RTL-to-GDSII implementation of a Lemmings4 finite state machine using Verilog HDL, Yosys, OpenROAD, and the Nangate45 standard-cell library. The project covers synthesis, floorplanning, placement, clock tree synthesis, routing, parasitic extraction, post-route static timing analysis, and GDSII layout inspection using KLayout
